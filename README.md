# CIT308 LankaMart Retail Dashboard

## Project Overview

LankaMart Retail Dashboard is an interactive data visualization project developed for the CIT308 - Data Science module.

This project focuses on analyzing retail transaction data and transforming raw data into meaningful business insights using Python-based data analysis and visualization techniques.

The dashboard was developed using Streamlit and provides an interactive platform to explore sales performance, revenue trends, profit analysis, product performance, and customer-related insights.

The main purpose of this project is to demonstrate the application of data science concepts in real-world retail business analysis.

# Installation and Setup

## Clone Repository


git clone https://github.com/your-username/CIT308-LankaMart-Dashboard.git


---

## Open Project Folder


cd CIT308-LankaMart-Dashboard


---

## Install Required Packages

Install the required Python libraries:


pip install -r requirements.txt


---

# Running the Dashboard

To run the Streamlit application:


streamlit run app.py


After executing the command, the dashboard will open automatically in the web browser.
